# SnapFile website (GitHub Pages)

Landing page for [SnapFile](https://github.com/mudot/SnapFile/).

## Public URLs (after Pages is enabled)

| Page | URL |
|------|-----|
| Home | https://mudot.github.io/SnapFile/ |
| Privacy | https://mudot.github.io/SnapFile/privacy.html |
| Terms | https://mudot.github.io/SnapFile/terms.html |

## Enable Pages

1. Copy all files from this folder into `docs/` on the `main` branch of mudot/SnapFile
2. GitHub → Settings → Pages → Source: **main** / **/docs**
3. Wait 1–3 minutes
