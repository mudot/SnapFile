Recursos

Feito para o momento em que um site pede um arquivo — sem procurar pasta no Explorer.

📥

Downloads recentes

Detecta arquivos baixados no navegador e os oferece prontos para anexar, com resolução automática do conteúdo quando possível.

📋

Imagens do clipboard

Copiou um print ou uma imagem? Ela pode aparecer no SnapFile para upload imediato, sem salvar no disco.

☁️

Google Drive opcional

Conecte sua conta, escolha um arquivo do Meu Drive e anexe no site. Você controla o login e o logout.

👁️

Preview lateral

Interface lista + preview: confira a imagem antes de confirmar. Enter ou clique para usar.

🔒

Local-first

Downloads e clipboard ficam no seu dispositivo. Não há servidor SnapFile guardando seus arquivos.

📂

Fallback nativo

Prefere o seletor do sistema? “Escolher no computador…” abre o diálogo nativo a qualquer momento.

Como funciona

Fluxo simples, do clique no site até o arquivo no formulário.

1

Baixe ou copie

Baixe um arquivo no navegador ou copie uma imagem (Ctrl+C / “Copiar imagem”).

2

Clique em enviar arquivo

Em qualquer site com campo de upload, o SnapFile abre no lugar do seletor nativo.

3

Escolha com preview

Veja a lista (Hoje / Ontem), confira o preview e confirme — ou use a aba Drive.

4

Upload normal

O arquivo vai para o input da página com os eventos padrão. O site recebe como um anexo comum.

Instalação (desenvolvedor)

Enquanto a extensão não está na Chrome Web Store, carregue a partir do repositório.

Load unpacked

1. Clone ou baixe o repositório
2. Abra chrome://extensions
3. Ative o Modo do desenvolvedor
4. “Carregar sem compactação” → pasta do projeto
5. Opcional: permita acesso a URLs de arquivo

Google Drive

Configure um OAuth Client ID no Google Cloud (tipo Extensão do Chrome), ative a Drive API e coloque o client ID no manifest.json. Detalhes no README do repositório.

Privacidade e Google APIs

Transparência alinhada à política de dados de usuário das Google API Services (Limited Use).

DadoUso
Downloads do navegador Metadados e conteúdo local para reanexar arquivos — só no seu dispositivo
Clipboard Apenas imagens, quando você copia ou abre o SnapFile
Google Drive Somente após “Conectar”; lista e baixa o arquivo que você escolher para o upload
Servidores SnapFile Não armazenamos seus arquivos em servidor nosso

Escopo OAuth: drive.readonly — necessário para listar arquivos do Meu Drive. Política completa: Privacy Policy. Você pode revogar o acesso em Conta Google → Acesso de apps.
