SnapFile Privacy Policy

Last updated: October 2, 2026 · Project: github.com/mudot/SnapFile

SnapFile (“the extension”) is a browser extension that helps you attach recent downloads, clipboard images, and optional Google Drive files to website upload fields.

1. Data we access

  • Browser downloads: metadata and, when possible, file content on your device, to offer quick re-attach.
  • Clipboard: image data only, when you copy an image or open SnapFile, to offer that image for upload.
  • Google Drive (optional): only after you click Connect and authorize. We may list files and download a file you select to attach it to the current website.

2. How we use data

Data is used solely to provide the SnapFile picker and attach features. We do not sell your data. We do not use Google user data for advertising.

3. Google user data (Limited Use)

SnapFile’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including Limited Use requirements. Google Drive data is used only to list and download files you choose for attaching to a web upload field. It is not used for ads, not sold, and not transferred for independent third-party use.

OAuth scope used: https://www.googleapis.com/auth/drive.readonly.

4. Storage

File cache and metadata are stored locally in your browser (extension storage / IndexedDB). We do not operate a SnapFile server that stores your Drive files. Google OAuth tokens are managed by the browser; you can sign out in SnapFile or revoke access at myaccount.google.com/permissions.

5. Sharing

We do not share your files with SnapFile-operated backends. When you attach a file to a website, that website receives the file as with any normal file upload you initiate.

6. Retention

Local cache is limited and can be cleared by removing extension data or uninstalling SnapFile. Disconnecting Google Drive ends Drive access for the extension.

7. Children

SnapFile is not directed at children under 13.

8. Changes

We may update this policy; the “Last updated” date will change. Material changes will be reflected on this page.

9. Contact

Open an issue on GitHub Issues or contact the maintainer via the repository.
